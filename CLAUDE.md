# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Не кодова база. Це робоча папка проєкту RADIX, яка містить:

- `assets/logo Radix/` — фірмовий стиль: `logobook Radix.pdf`, `Основний Логотип PNG/`, `Додаткові матеріали/`. Це канонічне джерело логотипу та брендингу для будь-яких поверхонь, що будуєш для RADIX.
- `assets/cases/` — десять PNG-зображень кейсів (`кейс 1.png` … `кейс 10.png`). Використовуй їх як реальну візуальну медіа коли збираєш сторінки/презентації для RADIX замість плейсхолдерів чи декоративних градієнтів.
- `.claude/rules/` — taste skill pack для frontend-генерації (див. нижче). Це не специфічне для RADIX, але активне в цьому каталозі.
- `.sixth/skills/` — порожня директорія, наразі неактивна.

Тут немає `package.json`, тестів, складальної системи. Команди build/lint/test не застосовні.

## Taste skill pack (`.claude/rules/`)

Це багатостильова система для frontend-завдань. **Завжди починай з `.claude/rules/SKILL.md`** — це роутер. Він обирає стиль (або поважає явний запит користувача), потім ти відкриваєш відповідну папку стилю (`brutalism/skill.md`, `dark-luxe/skill.md`, …) і `components/style-recipes.md` для патернів компонентів.

Ключові правила, які легко проґавити:

- Перевір `package.json` перед імпортом будь-якої сторонньої бібліотеки. Якщо її нема — спершу виведи команду установки.
- Default-стек: React/Next.js, Tailwind CSS, Server Components за замовчуванням, важка інтерактивність — у leaf client-компонентах.
- Іконки: `@phosphor-icons/react` або `@radix-ui/react-icons`. Без емодзі, якщо користувач явно не попросив.
- Hero: `min-h-[100dvh]`, ніколи `h-screen`. CSS Grid замість flex-math для основних розкладок.
- Реальні зображення обов'язкові в hero або перших двох секціях, коли вони доречні. Для RADIX-сторінок насамперед бери файли з `assets/cases/` та `assets/logo Radix/` — не вигадуй URL, не вставляй декоративні градієнти замість медіа.
- Перед використанням компонентного патерну з `components/*.md` (gsap-explore, aceternity-ui, reactbits, 21st-community) реально відкрий цей файл — не пропускай це, щоб зрізати кут.
- Заборонені AI-tells (детально в кожному `skill.md`): фіолетово-синій градієнт як головний акцент, gradient-text H1, три однакові feature-cards, generic CTA на кшталт "Get Started", `rounded-2xl` всюди, shadcn defaults без кастомізації.

## Мова

Інструкція з мови у системному промпті: всі пояснення українською, технічні терміни та ідентифікатори — в оригіналі. Файли стилю в `.claude/rules/` написані англійською — не перекладай їх.
